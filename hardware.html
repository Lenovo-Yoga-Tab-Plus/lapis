TB520FU · codename lapis

What the port actually boots.

Silicium starts from slot B, GRUB loads the kernel and the board device tree from the boot filesystem, and the root is an ext4 volume labeled eos-lapis. There is no initramfs.

Boot path

  1. The bootloader on boot_b is a Mu-Silicium RELEASE image.
  2. Silicium reads the EFI system partition on pstoredump. That volume is FAT16 with 4096-byte sectors. GRUB is EFI/BOOT/BOOTAA64.EFI.
  3. GRUB loads /Image and /dtbs/qcom/sm8650-lenovo-tb520fu.dtb from lenovocust, the ext4 filesystem labeled boot.
  4. The kernel command line is root=LABEL=eos-lapis rw rootwait console=tty0 clk_ignore_unused pd_ignore_unused regulator_ignore_unused ignore_loglevel.

Slot A keeps the Android boot image. From Linux, qbootctl -s a and a reboot select it. From fastboot, fastboot set_active a does the same. pstoredump and lenovocust are shared by both slots. The Linux images replace whatever those two partitions held.

flash.sh writes the root image to arch and leaves boot_a and userdata alone. flash-multiboot.sh asks for the boot slot and the root partition name. This guide uses boot_b in both install paths.

On the machine

  • The panel is the Tianma NT36532, dual-DSI, 2944×1840.
  • Wi-Fi is WCN7850. Plugged into a host, the tablet’s USB network is usb0 at 172.16.42.1/24.
  • The rear camera is a GC13A0 and the front camera is a GC13A2.
  • Six AW88461 amplifiers drive the speakers. The sound card name stays Lenovo-TB520FU.
  • The pogo keyboard and touchpad are used while the keyboard is attached. The lid blanks the screen. It does not suspend.
  • Sensors come from the ADSP through hexagonrpc.

Status

The panel, touch, pen, and folio cover work. Wi-Fi, Bluetooth, and the USB network work. Both cameras work. The speakers, the internal microphones, and the light sensor work. Closing the folio blanks the screen and does not suspend.

The accelerometer does not report an orientation. The proximity sensor does not send a reading. The compass is not enabled. The headset microphone is configured and has not been tested. A very short sound right after boot can clip. Suspend does not stay down while the tablet is plugged into a computer. After that wake the light sensor has stuck at a dark reading.
